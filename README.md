# 💖 Our Space

A cozy, private real-time web application built for two people to stay connected. Draw together live, drop cute stickers, chat, and share little moments no matter the distance.

## ✨ Features

* **Live P2P Drawing:** Draw together on a shared digital canvas in real-time using PeerJS.
* **Instant Chat:** Send text messages back and forth in your private room.
* **Stickers & Hearts:** Drop fun emojis and floating heart animations to let your partner know you care.
* **Moments Tracker:** Keeps a log of milestones and interactions in your shared space.
* **Mobile-Friendly:** Designed to look and feel like a native mobile app.

## 🚀 How to Use

1. Open the website (via GitHub Pages).
2. Enter your nickname.
3. One person clicks **"Create a Space"** and shares the generated Space Code with their partner.
4. The other person enters the code and clicks **"Join Partner's Space"**.
5. Enjoy your private connected canvas and chat!

## 🛠️ Built With

* **HTML5 Canvas** - For real-time drawing functionality
* **CSS3** - Custom iOS-inspired UI styling
* **JavaScript (ES6+)** - App logic and interactivity
* **PeerJS** - WebRTC peer-to-peer data channel connection
